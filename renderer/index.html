服务协议

Yorozuya 是一款完全在本机运行的 AI 陪伴助手，数据保存在你的设备（本机 MySQL 的 zhiban 库），我们不会上传你的对话、记忆或待办。

· 访客模式可免注册体验，但不保存任何记忆，关闭页面即清空。

· 注册账号后，对话、记忆、待办与成长记录会按账号隔离持久保存；密码以 PBKDF2-HMAC-SHA256 加盐哈希存储，不存明文。

· 模型接口需你自备兼容 OpenAI 的 API Key；留空则使用内置演示模式（能力有限）。

· 你有权随时导出或清空自己的全部数据。

帮助与反馈

万事屋怎么用

  • 左侧选「对话」直接开聊；「记忆 / 待办 / 成长」各有入口。
  • 对话页顶边栏右侧点一下就换陪伴你的成员（银时 / 神乐 / 新八），点完立即生效，主题整体跟着换肤。
  • 左下角可上传你的头像；登录账号后头像长期保存。
  • 未登录是「访客模式」：能聊天、能用待办，但不保存记忆，关页即清空。

反馈

遇到问题或想加功能，直接告诉开发者即可。本应用完全在本机运行，数据保存在你自己的 MySQL。
